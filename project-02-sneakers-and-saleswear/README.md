# SNEAKERS and Saleswear

Use the [cleaned practice CSV](data/sneakers-sales-cleaned.csv) to explore sales by product, brand, country, and payment method.

1. In Power BI Desktop, import the CSV and check the column types, especially the transaction date, quantity, and amount.
2. Create a total sales measure using the amount column.
3. Compare sales across brands, countries, and payment methods. Rank products by sales and plot the monthly trend.
4. Validate a few report totals against the source table.
