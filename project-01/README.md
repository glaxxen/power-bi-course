# Project Builders Power BI capstone

Build a Power BI sales report against the requirements in the [course outline](../docs/power-bi-course-outline.pdf).

Start with the source workbook provided by the instructor. Profile the data, set up fact and dimension tables, and check the keys and cardinality before building the report. Use filters, DAX, and visual interactions to meet the requirements. Include product rankings by sales, quantity, and profit, plus a view of sales trends over time.

The source workbook is provided separately.
